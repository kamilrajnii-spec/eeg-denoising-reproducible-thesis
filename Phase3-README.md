# Phase 3 Evaluation and Analysis

Phase 3 turns the Phase 2 prototype into a broader evaluation system.

It evaluates the trained Phase 2 checkpoint at:

- artifact types: blink, muscle, mixed
- target SNR levels: -5 dB, 0 dB, +5 dB
- methods: noisy input, wavelet-only, hybrid wavelet-to-DAE

All outputs are generated by scripts. No results are manually typed into CSV
files.

## Scripts

Run the full EEGdenoiseNet held-out evaluation:

```bash
python scripts/run_phase3_evaluation.py
```

Run paired statistical tests:

```bash
python scripts/run_phase3_statistics.py
```

Run ERP-like morphology preservation analysis:

```bash
python scripts/run_phase3_erp_analysis.py
```

Run public external validation using PhysioNet epochs with injected
EEGdenoiseNet artifacts:

```bash
python scripts/run_phase3_external_validation.py
```

Run larger latency profiling:

```bash
python scripts/profile_phase3_latency.py
```
